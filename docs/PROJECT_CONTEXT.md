# Contexto de proyecto
Actualizado: 2026-10-09.

## Confirmado por el propietario
Nombre VoxWave. Desarrollo para Creative Shock. Foco exclusivo en Parkinson y screening por voz. El funcionamiento offline es importante. Separar producción de video (incluido Seedance), plataforma/app y hardware. Repositorio GitHub privado denominado VoxWave.

## Alcance inicial
Construir una demostración explicable del recorrido: consentimiento, captura guiada, control de calidad, análisis local y presentación prudente de resultados. La utilidad clínica es una hipótesis por investigar; no hay cifras de rendimiento aprobadas.

## Por concretar
Usuarios y entorno de uso, protocolo de grabación, idiomas, dispositivos objetivo, requisitos de Creative Shock y fecha de entrega, datasets autorizados, stack, modelo y plan de validación. No se presupone acceso a pacientes ni datos clínicos.

## Límites
No ampliar a otras patologías. No confundir screening con diagnóstico. No depender de conexión permanente. Distinguir demostración sintética, prototipo funcional y validación clínica.
